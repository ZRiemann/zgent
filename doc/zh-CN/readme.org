* 项目概述

[[file:../../readme.org][项目主页]] | [[file:../en/readme.org][English Version]]

zgent 是由用户主导代码框架开发和思想验证的 ZetaX 项目。用户主导核心框架、
关键逻辑和设计方向，并保持对整体实现的完整理解。Agent 围绕这一方向配合完善
辅助代码、文档、构建集成和必要验证。

zeta_agent 主要由 Agent 开发维护，用户审查需要投入较多时间与精力。zgent 采用
不同的协作方式，让框架保持在用户能够理解和掌控的范围内。参考 zeta_agent
不代表采纳其架构、功能或里程碑。

* 当前实现

- C++ 应用运行时，包含 =zgent= 和内部 =zgent_core= 构建目标。
- 继承 =z::server=，组合持有 =z::nng::nng= 和应用内部的 HPX 运行时对象。
- =run()= 前台阻塞，使用 HPX 协作式常驻循环并响应信号退出。
- JSON 日志/NNG 配置，以及默认三个业务工作线程的 HPX INI 配置。
- 薄入口 =zbuild.py= 和基于 Forge 的项目构建定义。
- 五项 CTest 进程测试，覆盖配置、信号、启动失败和清理错误/异常。
- 尚未实现 Agent 业务逻辑或 Vault/API key 请求。

NNG 负责通信执行，HPX 负责应用业务任务。应用先停止并收敛工作，再结束 HPX，
最后释放 NNG。所有权、配置和错误语义见 [[file:../../BUILD.org::*Lifecycle and logging][生命周期与日志说明]]。
版本记录在 [[file:../../VERSION][VERSION]]；版本号或已有产物不代表功能完整或通过当前验证。
