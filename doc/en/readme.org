* Overview

[[file:../../readme.org][Project home]] | [[file:../zh-CN/readme.org][中文版]]

zgent is a user-led ZetaX project for developing a code framework and
validating ideas. The user leads the core framework, key logic, and design
direction, and maintains a complete understanding of the implementation.
Agents assist with auxiliary code, documentation, build integration, and
focused verification within that direction.

zeta_agent is primarily developed and maintained by agents, requiring
significant user effort to review. zgent uses a different collaboration
model to keep the framework understandable and under the user's control.
Referencing zeta_agent does not adopt its architecture, features, or milestones.

* Current implementation

- A C++ application runtime with =zgent= and internal =zgent_core= targets.
- A =z::server= subclass composing =z::nng::nng= and a local HPX runtime owner.
- A foreground, blocking =run()= with an HPX cooperative loop and signal shutdown.
- JSON logging/NNG configuration and an HPX INI with three business workers.
- A thin =zbuild.py= and project-owned build definition using Forge.
- Five CTest process tests covering configuration, signals, startup failures,
  and cleanup errors/exceptions.
- No implemented agent business logic or Vault/API key requests.

NNG owns communication execution; HPX owns application business tasks.
The application stops/drains work before finalizing HPX, then releases NNG.
See [[file:../../BUILD.org::*Lifecycle and logging][Lifecycle and logging]] for ownership, configuration, and error semantics.
The version is recorded in [[file:../../VERSION][VERSION]]; a version number or existing
artifact is not a statement of feature completeness or current verification.
